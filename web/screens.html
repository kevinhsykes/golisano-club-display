TV screens

Each screen below is a web page built for a 16:9 television at 1080p or 4K. Open its address full screen in kiosk mode on the device that drives the TV; the page refreshes itself and keeps the last prices through a network drop. Prices are a saved snapshot refreshed every 15 minutes during market hours. For phones and laptops use the portfolio page.

Options for any TV screen

Add to the addressEffect
?panel=h1 · h2 · movers · chartPin one panel instead of rotating through all four.
?rotate=40Seconds per panel when rotating (default 20).
?amounts=hidePercent only: no dollar values on screen.
Combine with &Example: tv.html?panel=movers&amounts=hide

Setting up a screen (the school's TVs run Yodeck)

DeviceHow
Yodeck (the school's signage players)In Yodeck: Media → Web Pages → Add, name it, paste one of the addresses above, save. Then show it on a screen directly, or add it to a playlist or layout. Under Advanced settings, leave Refresh Web Page off or set it to a few hours: the page already refreshes its own prices every minute and reloads itself every 6 hours. No login, no account, no key is needed; the page is public. Use the rotating TV view as a single-item show so it stays on screen, or pin one panel per screen.
Existing signage playerAdd the address as a web-page item. Any system that shows a URL works.
Chrome or Edge on a PC or mini PCRun the browser with --kiosk https://kevinhsykes.github.io/golisano-club-display/tv.html, or press F11 for full screen.
Chromecast with Google TV, Fire TV, Raspberry PiInstall a kiosk browser app and set the address as its home page.
